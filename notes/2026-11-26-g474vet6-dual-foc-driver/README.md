## 1. 方案亮点与核心参数

- **单芯片真双轴同步 FOC**：`STM32G474VET6`（170MHz / 512KB Flash / 128KB RAM / CORDIC + FMAC / 5× ADC）自带完整 `TIM1` + `TIM8` 互补 PWM 与独立多 ADC，两路电机 20~40kHz 电流环可硬件同步采样、互不抢占。
- **全外设独立零复用**：利用 LQFP-100 充足引脚，实现：
  - `SPI1` 独占编码器 1、`SPI3` 独占编码器 2、`SPI2` 专供两颗 `DRV8320S` 配置；
  - `PA11/PA12` 独立留给 **USB-C** 直连电脑调参看波形，`FDCAN1` 挪至 `PD0/PD1` 零冲突；
  - 剩余 **30+ 个富余 GPIO** 按功能整齐引出到两组 `2.54mm 2×10P` 排针（带 `5V / 3.3V / GND`）。
- **相线串联全占空比电流采样**：每路电机 U/V 两相串联采样电阻 + `INA240A2`（增益 50 V/V，增强型 PWM 共模抑制）：
  $$I_{\max} = \pm \frac{1.65\text{V}}{50 \times R_{\text{shunt}}}$$
  - 贴 **`1.5mΩ`** (2512) → 量程 **±22A**（推荐 5010 电机）；
  - 贴 **`1.0mΩ`** (2512) → 量程 **±33A**（更大峰值余量，可直接复用旧料）。
- **整板纯 BOM 估算**：约 **¥180 ~ ¥230 / 块**（折合单轴 ~¥100，走公司报销全一线原厂料，省心耐用）。

## 3. 富余引脚扩展排针规划（2× `2×10P`）

两组 `2.54mm 2×10P` 排针统一放在板子**弱电侧边缘**，顶层丝印务必标清每个引脚名称和电源地：

### 排针 `J_EXP1`：通信 & 定时 / 开关扩展（`2×10P`）
- **电源（4 脚）**：`5V`、`3.3V`、`GND` × 2
- **I2C / 串口扩展（7 脚，接 IMU 陀螺仪、OLED、蓝牙/Wi-Fi）**：
  - `PB10` (`I2C2_SCL` / `USART3_TX`)、`PB11` (`I2C2_SDA` / `USART3_RX`)
  - `PD5` (`USART2_TX`)、`PD6` (`USART2_RX`)
  - `PA8` (`I2C2_SDA` / `MCO`)、`PA9` (`I2C2_SCL`)、`PA10`
- **舵机 PWM / 限位开关 / 急停按钮（9 脚）**：
  - `PD13` (`TIM4_CH2`)、`PD14` (`TIM4_CH3`)、`PD15` (`TIM4_CH4`)
  - `PD2`、`PD3`、`PD4`、`PD7`、`PB9` (`TIM17_CH1`)、`PC9`

### 排针 `J_EXP2`：模拟 ADC + 通用 GPIO 扩展（`2×10P`）
- **电源（3 脚）**：`3.3V`、`GND` × 2
- **富余 ADC 通道（6 脚，接电位器、压力/温度/外部电流传感器）**：
  - `PA3` (`ADC1_IN4`)、`PB2` (`ADC2_IN12`)
  - `PC2` (`ADC12_IN8`)、`PC3` (`ADC12_IN9`)、`PC4` (`ADC2_IN5`)、`PC5` (`ADC2_IN11`)
- **富余通用 GPIO（11 脚，可做按键、RGB、继电器、外扩模块）**：
  - `PE0`、`PE1`、`PE2`、`PE3`、`PE4`、`PE5`、`PE6`、`PE7`、`PE14`、`PE15`、`PC14`（另 `PC15` 可按需引出）

## 5. 原理图防翻车铁律（必看）

1. **`INA240` 封装与输入铁律**
   - `INA240A2DR` (**SOIC-8**) 与 `INA240A2PWR` (**TSSOP-8**) **引脚顺序完全不同**，原理图符号与实物后缀必须一一对应！
   - `IN+`（接半桥中点侧）和 `IN-`（接电机焊盘侧）**严禁串任何电阻电容**，直接从采样电阻焊盘内侧开尔文拉差分线接入；RC 滤波（`33Ω + 1nF`）只放在 `OUT` 到 MCU ADC 之间。
   - **免基准源 1.65V 偏置**：`VS` 和 `REF1` 接 `VDDA (3.3V)`（就近放 `0.1µF`），`GND` 和 `REF2` 接 `AGND`，0A 时输出精准停在 `1.65V`。
2. **`DRV8320S` 三条保命线（每颗都要核对！）**
   - `CPH` (Pin 1) 与 `CPL` (Pin 32) 之间接 **`47nF / 50V (X7R)`**；
   - **`VCP` (Pin 2) 的 `1µF / 50V (X7R)` 电容另一端必须接 `VM (24V)`，严禁接 GND！**
   - **`DVDD` (Pin 24) 是内部稳压输出，只接 `1µF` 电容到地，严禁连外部 `3.3V`！**
   - `nFAULT` (Pin 17) 和 `SDO` (Pin 18) 各加 **`10kΩ` 上拉到 `3.3V`**；`SLA/SLB/SLC` (Pin 8/9/16) 分别连到各自下管 MOS 的 Source 焊盘。
3. **`LMR14020` 5V 反馈配比**
   - 基准 $V_{FB} = 0.75\text{V}$，用 **`R_top = 68kΩ (1%)`**、**`R_bot = 12kΩ (1%)`** → 精准输出 **`5.00V`**。
4. **`TJA1051T/3` 双电源别接错**
   - `Pin 3 (VCC)` 必须接 **`5V`**（CAN 差分电平需要 5V 驱动），`Pin 5 (VIO)` 接 **`3.3V`**（匹配 STM32 IO 电平）。
5. **USB-C 与 MCU 启动**
   - Type-C 的 `CC1`、`CC2` 各自独立接一颗 **`5.1kΩ`** 下拉电阻到 GND（不要合并共用一颗电阻）；
   - `STM32G474` 的 **`PB8 (BOOT0)`** 加 `10kΩ` 下拉到地，`VREF+` 接干净的 `VDDA (3.3V)` 并配 `1µF + 100nF` 退耦电容。

## 6. 四层板 PCB 布局与投板前自检清单

### 四层板叠层与布局建议（推荐 **2oz 外层铜厚**）
- **叠层**：`Top`（器件 + 功率铜皮）→ `Inner1`（完整 `GND` 参考平面）→ `Inner2`（`24V` 功率铜皮 + `5V/3.3V` 分区）→ `Bottom`（辅助走线 + 散热敷铜）。
- **分区**：采用 **“上弱电 / 下双功率对称”**（或 **“左弱电 / 右上下双功率对称”**）：
  - `XT60` 放双功率区中间，左右/上下对称分给 M1、M2 两路半桥；
  - 画完 M1 功率模块后直接**模块复用**给 M2，省一半时间且对称美观；
  - 两组 `2×10P` 扩展排针、USB-C、CAN、SWD 全部放在弱电侧边缘，远离 24V 大电流区。

### 导出 Gerber 前 30 秒自检

- [ ] 四颗 `INA240` 封装后缀与引脚一致，`IN+/IN-` 无串联电阻，开尔文采样线从 2512 焊盘内侧引出。
