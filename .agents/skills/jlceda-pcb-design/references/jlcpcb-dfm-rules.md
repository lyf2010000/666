# 嘉立创（JLCPCB）DFM 工艺参数与布板设计速查

> 本文档作为 `jlceda-pcb-design` Skill 的按需参考资料。具体打样前若涉及特殊工艺（如阻抗控制、盘中孔、超过 2oz 铜厚），仍应以嘉立创最新下单页面实时参数为准。

---

## 1. 常规免费/经济打样工艺边界（安全推荐值 vs 极限值）

| 参数项 | 2 层板（1oz）推荐 / 极限 | 4 层板（外层 1oz）推荐 / 极限 | 4 层板（外层 **2oz** 功率板）推荐 / 极限 |
| :--- | :--- | :--- | :--- |
| **信号线宽 / 线距** | `≥ 6mil / 6mil`（极限 5/5mil） | `≥ 5mil / 5mil`（极限 3.5/3.5mil） | `≥ 8mil / 8mil`（2oz 外层极限约 6.5~8mil，慎用过细线） |
| **过孔内径 / 外径** | `0.3mm / 0.6mm`（极限 0.3/0.45mm） | `0.25~0.3mm / 0.5~0.6mm`（极限 0.15/0.3mm，小孔可能加价） | `0.3mm / 0.6mm`（大电流导流用 `0.3~0.4mm` 阵列） |
| **铜皮/走线到板边** | `≥ 0.3mm`（V-Cut 拼板 `≥ 0.4mm`） | `≥ 0.3mm`（内层铜皮建议内缩 `≥ 0.4~0.5mm`） | `≥ 0.4mm`（内层铜皮内缩 `≥ 0.5mm`） |
| **阻焊桥（Solder Mask Bridge）** | 绿油最稳（约 `≥ 0.1mm`）；黑/白油桥更宽，密脚 IC 推荐**绿油** | 同左，QFN/LQFP-100 优先绿油防连锡 | 同左，强烈建议绿油 |
| **丝印线宽 / 字高** | 线宽 `≥ 6mil`（0.15mm），字高 `≥ 32~40mil`（0.8~1.0mm） | 同左，严禁压焊盘和开窗过孔 | 同左 |
| **钻孔到铜皮间距** | `≥ 0.25mm`（10mil） | `≥ 0.25mm`（10mil） | `≥ 0.3mm`（12mil） |

> **经济性提示**：
> - 四层板默认 **盘中孔树脂塞孔 + 电镀盖帽** 在嘉立创多数活动/常规四层板已免费支持，但仍需确认下单页勾选状态；若放普通导热过孔在 EPAD 下，建议 `0.3mm` 内径并注意底部盖油或钢网开窗防漏锡。
> - 4 层板常规叠层：`JLC04161H-7628`（非严格阻抗通用）或 `JLC04161H-3313`（USB 90Ω / CAN 120Ω 差分阻抗更易控制）。

## 2. 推荐四层功率/控制板叠层结构

- **Top Layer（外层 1oz / 2oz）**：核心器件摆放、短粗功率铜皮、关键模拟/差分走线。
- **Inner1 Layer（内层 0.5oz / 1oz）**：**完整 `GND` 参考平面**（尽量不分割，避免高速线跨分割；若区分功率地与模拟地，采用分区布局 + 单点汇聚思路）。
- **Inner2 Layer（内层 0.5oz / 1oz）**：主电源铜皮（如 `24V` 功率区）+ 弱电电源分区（`5V`、`3.3V`、`VDDA`）。
- **Bottom Layer（外层 1oz / 2oz）**：辅助信号走线、次要器件、大面积 `GND` 散热敷铜（必要时功率区开窗加锡增流）。

## 3. 线宽与载流参考（IPC-2152 工程近似，温升 ΔT ≈ 20°C）

| 持续电流 | 外层 1oz 建议线宽 | 外层 **2oz** 建议线宽 | 工程建议 |
| :---: | :---: | :---: | :--- |
| `1A` | `≥ 15~20mil` (0.4~0.5mm) | `≥ 10~15mil` (0.25~0.4mm) | 普通供电/3.3V 支路 |
| `3A` | `≥ 50~60mil` (1.3~1.5mm) | `≥ 25~35mil` (0.65~0.9mm) | 5V 总线 / 中等电流 |
| `5A` | `≥ 100mil` (2.5mm) | `≥ 50~60mil` (1.3~1.5mm) | 局部铺铜更佳 |
| `10A` | 铺铜 `≥ 5mm`（或双层并联） | 铺铜 `≥ 2.5~3mm` | 建议多过孔并联换层 |
| `20A+` | 强烈建议改 **2oz** + 双面铺铜/开窗加锡 | 铺铜 `≥ 6~8mm` + 过孔阵列 | 功率回路越短越宽越好 |

- **单颗过孔载流（工程保守估算）**：内径 `0.3mm` 过孔持续载流约 `0.8~1.0A`；`10A` 换层至少放 `10~15` 颗 `0.3mm` 过孔阵列，留足余量。

## 4. 嘉立创 SMT 贴片（PCBA）防踩坑规则

1. **基础库 vs 扩展库**：阻容感优先选**基础库（Basic Parts）**，可避免每颗扩展库物料的换料费；尽量统一阻容封装（如全板 0603）和合并相同阻值（如 `10kΩ`、`100nF`）。
2. **单面贴片优先**：核心贴片器件全部放在 **Top 面**，避免双面 SMT 带来的额外费用和工艺风险。
3. **极性与方向核对（必检）**：
   - 有极性器件（IC、二极管、LED、钽电容、电解电容、排针）在嘉立创下单页 **3D / SMT 预览器**中必须逐颗肉眼核对 Pin 1 和阴极方向，不可盲信默认 CPL 角度。
4. **手工焊与 SMT 混合**：XT60、MR60、大电解电容、排针等大体积插件可标为 **DNP（不贴片）**，回板后手工补焊。
