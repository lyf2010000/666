# 嵌入式 / 功率驱动 / FOC 电机驱动板硬件自检清单

> 结合 STM32（如 STM32G431 / STM32G474）+ 三相预驱（如 DRV8320S）+ 相线采样（如 INA240）+ CAN/USB-C 典型架构整理，按模块逐项核对，防止首板炸机或无法点亮。

---

## 1. 主控 MCU（STM32 系列）
- [ ] **引脚复用零冲突**：已通过 STM32CubeMX (`.ioc`) 验证所有引脚，特别核查 `I2C`、`SPI`、互补 `TIM`（`CHx`/`CHxN`）、`ADC` 通道映射（切勿凭印象假定某引脚支持某外设）。
- [ ] **启动与烧录**：`BOOT0`（如 STM32G4 的 `PB8`）已加 `10kΩ` 下拉到地；`NRST` 有 `100nF` 滤波电容；`SWDIO`/`SWCLK`/`GND`/`3V3`（最好带 `NRST`）引出且线序标注清晰。
- [ ] **电源与模拟基准**：每组 `VDD` 就近放置 `100nF` 退耦电容；`VDDA` / `VREF+` 干净供电并配 `1µF + 100nF`（必要时串磁珠与数字 3.3V 隔离）。
- [ ] **外部晶振**：晶振紧贴 `OSC_IN`/`OSC_OUT`，匹配电容按 $C_L$ 选型（常见 12pF 晶振配 18~20pF），晶振下方净空或完整地参考、周围包地，不穿高速/功率线。

## 2. 电源树（24V → 5V Buck → 3.3V LDO）
- [ ] **输入防护**：母线输入端靠近电源座子放置 TVS（如 24V 系统用 `SMDJ30A`，击穿电压高于最高母线电压且低于 Buck/MOS 耐压）+ 大容量低 ESR 电解电容（50V 耐压）+ 高频 MLCC。
- [ ] **Buck 芯片（如 LMR14020 / TPS5430 等）**：
  - 反馈分压电阻按手册公式逐一复算（例如 `LMR14020` $V_{FB}=0.75\text{V}$，$68\text{k}\Omega / 12\text{k}\Omega \Rightarrow 5.00\text{V}$）。
  - 自举电容 `BOOT-SW`、续流肖特基二极管（耐压 ≥ 40~60V，阳极接 GND、阴极接 `SW`）与功率电感构成**最小环路**，反馈线远离 `SW` 开关节点。
  - 底部散热焊盘（EPAD）已接地并打过孔阵列。
- [ ] **LDO（5V → 3.3V）**：输入/输出电容容值与耐压满足手册稳定性要求，散热足够承载 MCU + 编码器 + 外设总电流。

## 3. 三相预驱与功率半桥（如 DRV8320S + 6× MOS）
- [ ] **`DRV8320S` 三条保命线**：
  1. `CPH` 与 `CPL` 之间接 `47nF / 50V (X7R)` 飞电容；
  2. **`VCP` 的 `1µF / 50V (X7R)` 电容另一端接 `VM (24V)`，严禁接 GND！**
  3. **`DVDD` 是内部稳压输出，只接 `1µF` 电容到地，严禁连外部 `3.3V`！**
- [ ] **开漏与控制信号**：`nFAULT` 和 `SDO` 均已加 `10kΩ` 上拉到 `3.3V`；`ENABLE` 有明确下拉或受控默认关闭态；SPI 独立片选无冲突。
- [ ] **栅极驱动与半桥**：
  - 栅极串联电阻（如 `10Ω`）紧靠 MOSFET 栅极放置；
  - `SLA`/`SLB`/`SLC` 分别接到各自下管 MOS 的 Source 焊盘；
  - 每相半桥紧贴放置 `10µF / 50V X7R` 去耦 MLCC，缩短高频换流环路；
  - MOS 选型耐压 ≥ 2× 母线电压（24V 系统用 60V MOS），散热焊盘充分铺铜并打散热过孔。

## 4. 相线电流采样（如 INA240）
- [ ] **封装与引脚铁律**：确认实物型号后缀与原理图/PCB 封装完全一致（**`INA240A2DR` SOIC-8 与 `INA240A2PWR` TSSOP-8 引脚定义完全不同**）。
- [ ] **量程核对**：3.3V 供电、1.65V 中点偏置下 $I_{\max} = \pm \frac{1.65\text{V}}{\text{Gain} \times R_{\text{shunt}}}$（如 Gain=50 配 `1.5mΩ` → `±22A`，配 `1.0mΩ` → `±33A`；严禁 50 倍增益误配 `5mΩ` 导致提前饱和）。
- [ ] **开尔文采样布线**：
  - `IN+` / `IN-` **严禁串联电阻电容**，直接从采样电阻（2512）焊盘内侧拉成对差分线直连运放输入；
  - RC 抗混叠滤波（如 `33Ω + 1nF`）只放在 `OUT` 与 MCU ADC 引脚之间，并紧靠 MCU ADC 引脚。
- [ ] **偏置与退耦**：`VS`/`REF1` 接 `VDDA (3.3V)` 就近放 `0.1µF`，`GND`/`REF2` 接 `AGND`。

## 5. 通信、编码器与扩展接口
- [ ] **USB-C**：`CC1`、`CC2` **各自独立**接一颗 `5.1kΩ` 下拉到 GND（不可共用一颗）；`D+`/`D-` 走差分并配 ESD（如 `USBLC6-2SC6`）；外壳按规范接地/阻容接地。
- [ ] **CAN（如 TJA1051T/3）**：`VCC` 接 **`5V`**、`VIO` 接 **`3.3V`**；`CANH`/`CANL` 靠座子放 `PESD1CAN`；预留 `120Ω` 终端电阻（可用跳线/0Ω 选择是否启用）。
- [ ] **编码器（如 MT6701）与排针**：磁编码器确认配**径向充磁**磁铁及安装气隙；所有外扩排针、调试口、电源口在顶层丝印逐脚标明名称与极性。
